Alur baru Penjualan & Lelang

Gambaran tampilan untuk disetujui sebelum dibangun. Tiap halaman punya bar biru "Mockup · pilih keadaan" untuk melihat tahap yang berbeda. Kotak bergaris putus-putus adalah catatan, bukan bagian tampilan.

1. Property for Sale · Booking fee

Belum login → tersedia → konfirmasi → menunggu bayar → berhasil / dibooking orang lain / kedaluwarsa.

2. Lelang / Cessie · Deposit & bid

Belum login / belum dibuka → deposit → bid (unggul / tersalip) → menang / kalah → lunas / gagal bayar / dibatalkan.

3. My Bids

Semua lelang yang diikuti, status deposit, posisi bid, tagihan pelunasan.

4. Wallet

Deposit yang dikembalikan masuk saldo, lalu ditarik ke rekening.

Panel admin

5. Admin · Bookings

Antrean per status, tandai terjual, batalkan (refund ke saldo / hangus), bayar ganda, form booking fee %.

6. Admin · Auctions

Daftar lelang, peserta & deposit, riwayat bid, pelunasan, gagal bayar, tanpa pemenang, form deposit %.

Sudah disepakati

  • Penjualan memakai booking fee; persentasenya diatur admin per properti.
  • Lelang wajib deposit, minimal 5%, persentase diatur admin per properti.
  • Deposit peserta yang kalah masuk saldo, ditarik sendiri.
  • Pemenang melunasi lewat web. Cessie sama dengan lelang.

Masih perlu keputusan

  1. Booking fee: jika pembeli batal, dikembalikan atau hangus? Memotong harga?
  2. Sisa pembayaran penjualan lewat web atau di luar web?
  3. Deposit pemenang memotong pelunasan?
  4. Batas waktu pelunasan berapa hari? Jika tidak melunasi, deposit hangus?
  5. Deposit per lelang atau sekali untuk semua lelang?
